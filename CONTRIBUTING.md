# 🤝 Contribuir a PAU Biología

Agradecemos tu interés en mejorar esta plataforma.

## Flujo de trabajo

1. **Fork** del repositorio
2. **Crear rama** feature
```bash
   git checkout -b feature/mi-mejora
```
3. **Hacer cambios** y commit
```bash
   git commit -m "feature: descripción"
```
4. **Push** a tu fork
```bash
   git push origin feature/mi-mejora
```
5. **Pull Request** con descripción clara

## Estándares de código

- **Python:** PEP 8
- **JavaScript:** 2 espacios indentación
- **Commits:** Mensajes en español, descriptivos
- **Tests:** Ejecutar antes de PR

## Áreas de mejora

- Automatización de carga de nuevos años
- Integración WhatsApp Bot
- Sistema de evaluación automática
- Despliegue en producción
